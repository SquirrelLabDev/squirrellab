Gestionnaire de tokens

Un "jeton" partagé pour travailler à plusieurs sur un même fichier (rapport Power BI, etc.) sans se marcher dessus.

Cette application se pilote par des liens de session. Si on vous a partagé un lien /session/..., ouvrez-le directement. Si vous êtes administrateur·rice, rendez-vous sur la page d'administration pour créer une session et obtenir un lien à partager.
