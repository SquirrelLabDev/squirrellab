Gestionnaire de tokens

Un "jeton" partagé pour travailler à plusieurs sur un même fichier (rapport Power BI, etc.) sans se marcher dessus.

Si on vous a partagé un lien /session/..., ouvrez-le directement : c'est tout ce qu'il vous faut pour prendre part à une session.

Pour créer votre propre session (privée : vous seul·e la voyez, jusqu'à ce que vous en partagiez le lien), créez-vous un compte dans votre espace.
